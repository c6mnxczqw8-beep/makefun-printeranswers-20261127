# The Printer Finally Answers — entry

A program/v1 entry for the make.fun "The Printer Finally Answers" bounty.
`main.py` writes the entry text to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable
is set). Gate: 1 to 240 characters. One line in the office printer's voice, answering the jams, the error codes and the thumps. See `CANDIDATES.md` for the drafts the
winner was picked from.
